# 🛒 AlcoBrake E-Commerce Dashboard

> A full-stack enterprise e-commerce web application with product management, order processing, user authentication and admin dashboard — built with Python & Flask.

[![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)](https://python.org)
[![Flask](https://img.shields.io/badge/Flask-3.0-green.svg)](https://flask.palletsprojects.com)

---

## ✨ Features

- 🔐 **Secure Login** — Role-based authentication (Admin / Customer)
- 📦 **Product Management** — Add, edit, delete products with categories and stock tracking
- 🛍️ **Order Management** — Place orders, update status (Pending → Processing → Shipped → Delivered)
- 👥 **User Management** — View registered users and roles
- 📊 **Dashboard** — Revenue, orders, low stock alerts and quick stats
- 💾 **Persistent Storage** — JSON file storage (Collections Framework equivalent)

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask, REST API (CRUD), Session Auth
- **Frontend:** Vanilla JS, HTML5, CSS3
- **Storage:** JSON File Storage
- **Deploy:** Render, Gunicorn
